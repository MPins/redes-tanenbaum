# Exercício 1.05

## Enunciado

Uma alternativa a uma LAN é simplesmente um grande sistema de tempo compartilhado (*timesharing*), com terminais para todos os usuários. Cite duas vantagens de um sistema cliente-servidor que utiliza uma LAN.


---

## Resolução — @seu-usuario

As duas prinicipais vantagens de sistemas cliente-servidor frente ao sistema centralizado com terminais "burros" seriam:

* **Processamento distribuído**: os clientes executam parte do trabalho localmente, reduzindo a carga sobre o servidor central e oferecendo interfaces mais responsivas.

* **Crescimento incremental e menor custo**: é possível ampliar o sistema adicionando computadores e servidores comuns conforme necessário, sem substituir ou expandir um único computador central de grande porte.
