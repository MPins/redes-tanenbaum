# Exercício 3.3

## Enunciado

Qual é o overhead máximo no algoritmo de inserção de bytes (*byte stuffing*)?

---

## Resolução — @Pins

O overhead máximo é 1 byte para cada byte de dados caso sejam transmitidos apenas ESC e FLAG, ou seja, o overhead máximo é de 100%.
