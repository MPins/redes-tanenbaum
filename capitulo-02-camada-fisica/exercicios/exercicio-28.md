# Exercício 2.28

## Enunciado

Na Fig. 2-22, há quatro estações que podem transmitir. Suponha que mais quatro estações sejam adicionadas. Forneça as sequências de chips dessas estações.

---

## Resolução — @Pins

Estas são as sequências de chips das quatro estações apresentadas na Fig. 2-22:
```
A = (-1 -1 -1 +1 +1 -1 +1 +1)
B = (-1 -1 +1 -1 +1 +1 +1 -1)
C = (-1 +1 -1 +1 +1 +1 -1 -1)
D = (-1 +1 -1 -1 -1 -1 +1 -1)
```

Cada uma deve ter exatamente 4 coincidências e 4 discrepâncias com todas as outras. Com 8 chips o número máximo de estações é 8, seguem as 4 possíveis adicionais:
```
E = (-1 -1 -1 -1 -1 +1 -1 +1)
F = (-1 -1 +1 +1 -1 -1 -1 -1)
G = (-1 +1 +1 -1 +1 -1 -1 +1)
H = (-1 +1 +1 +1 -1 +1 +1 +1)
```

**Confiança:** alta  
**Referência:** subcapítulo 2.4.4 - multiplexação
